# Collatz critical reader

This is the source-faithful critical/expository reader for the durable Collatz
reconstruction. Compile `main.tex` with pdfLaTeX. The mathematical source
files are under `chapters/`.

The reader keeps published statements, independently supplied repairs, finite
certificates, implementation findings, and nonclaims visibly distinct. It is
not the separately authored research programme and it does not claim a proof
of the Collatz conjecture.

The Overleaf package contains no copyrighted source PDFs or book scans. Those
are read and cited locally; only original exposition, bibliographic data, and
permitted audit/certificate material are uploaded.
