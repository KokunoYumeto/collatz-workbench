## Commands

From the repository root:

```sh
python -B collatz_reconstruction/research_program/bilateral_root_bounds_20260916/replay.py
python -B collatz_reconstruction/research_program/bilateral_root_bounds_20260916/replay.py --full --predecessor
python -B collatz_reconstruction/research_program/bilateral_root_bounds_20260916/bilateral_control.py layer 2 6

```

The first replay checks all file identities, both structural executions, the
complete pair ledger through an independent auditor, and invalid-ledger controls.
The full replay additionally rebuilds both complete source scans and their
independent all-row audit. `--emit-dir PATH` retains generated ledgers and results;
otherwise temporary outputs are removed after their byte identities are checked.
The optional predecessor flag executes the preserved first-jet ordinary/optimized
pair. No network request occurs during these commands.

`verification.json` contains all selected new families, original point witnesses,
and complete structural results. `window_certificate.json` records the two full
source executions and independent audit. The compressed ledgers are in the
external delivery package and can also be regenerated by the commands above.
They are not represented by a finite sample.
